# API

The API has two endpoints.

## Endpoints

### GET /items

Lists items. See the [setup notes][setup-notes].

### POST /items

Adds an item. Configuration is described in [configure notes](../guide/setup.md#notes-1).

## Errors

Errors are described in [the setup guide](../guide/setup.md#errors), a section that does not
exist. Install steps for a Mac are in [macOS](../guide/setup.md#macos).
